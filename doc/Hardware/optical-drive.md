# 光驱

光驱（Optical Disc Drive）用于读取和写入光盘介质。

## 光盘类型

### 只读光盘
- **CD-ROM**：700 MB
- **DVD-ROM**：4.7 GB（单层）/ 8.5 GB（双层）
- **BD-ROM（蓝光）**：25 GB（单层）/ 50 GB（双层）

### 可写光盘
- **CD-R / CD-RW**：一次性写入 / 可擦写
- **DVD-R / DVD+R**：一次性写入
- **DVD-RW / DVD+RW**：可擦写
- **BD-R / BD-RE**：蓝光刻录 / 可擦写

## 光驱类型

- **内置光驱**：安装在机箱 5.25 英寸位
- **外置光驱**：通过 USB 连接，便携
- **笔记本光驱**：超薄设计，用于笔记本电脑

## 接口

- **SATA**：主流接口
- **USB**：外置光驱常用
- **IDE / PATA**：旧设备接口

## 读取速度

- CD：最高 52X（约 7.8 MB/s）
- DVD：最高 16X（约 22 MB/s）
- BD：最高 12X（约 54 MB/s）

## 使用场景

- 安装操作系统（旧电脑）
- 播放音乐 CD / 电影 DVD / 蓝光影碟
- 数据备份和归档
- 软件安装光盘
