# 硬盘与固态硬盘

存储设备用于长期保存数据，分为 HDD 和 SSD 两大类。

## 机械硬盘（HDD）

- **原理**：磁头读取旋转磁盘上的数据
- **接口**：SATA 3.0（6Gbps）
- **转速**：5400 RPM / 7200 RPM
- **优点**：容量大，价格便宜
- **缺点**：速度慢，有噪音，易受震动影响
- **适用**：大容量数据存储（照片、视频、游戏库）

## 固态硬盘（SSD）

- **原理**：闪存芯片存储数据，无机械部件
- **优点**：速度快，无噪音，抗震
- **缺点**：价格相对较高，写入寿命有限

### 主流 SSD 类型

- **SATA SSD**：接口与 HDD 相同，速度上限约 550 MB/s
- **M.2 SATA**：M.2 接口，使用 SATA 协议
- **M.2 NVMe**：M.2 接口，使用 NVMe 协议，速度可达 7000+ MB/s
- **PCIe SSD**：插在 PCIe 插槽上，速度最快

## 选购要点

- 系统盘优先选择 NVMe SSD
- 数据盘可选择大容量 HDD 或 SATA SSD
- 注意 M.2 接口类型（M key / B key）和长度（2230 / 2242 / 2280）
- 确认主板支持的 PCIe 版本（3.0 / 4.0 / 5.0）
