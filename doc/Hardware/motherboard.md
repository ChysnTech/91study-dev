# 主板

主板（Motherboard）是计算机的核心电路板，连接所有硬件组件。

## 主要组成部分

- **CPU 插槽**：安装中央处理器
- **内存插槽**：安装 RAM 内存条
- **PCIe 插槽**：安装显卡、网卡等扩展卡
- **芯片组**：控制数据在各组件间传输
- **I/O 接口**：USB、音频、网口等

## 主板尺寸规格

- **ATX**：标准尺寸，扩展性好
- **Micro-ATX**：小型 ATX，适合紧凑机箱
- **Mini-ITX**：迷你尺寸，适合 HTPC

## 选购要点

- 确认 CPU 插槽类型与处理器兼容
- 确认内存类型（DDR4 / DDR5）和插槽数量
- 确认 PCIe 版本（4.0 / 5.0）
- 确认 M.2 接口数量和版本
