# 显卡

显卡（Graphics Card）负责将计算机数据转换为图像信号输出到显示器。

## 主要品牌

- **NVIDIA**：GeForce 系列（RTX 40、50 系列）
- **AMD**：Radeon 系列（RX 7000、8000 系列）
- **Intel**：Arc 系列（A 系列、B 系列）

## 关键参数

- **GPU 核心**：决定性能的核心芯片
- **显存（VRAM）**：存储图像数据（4GB / 8GB / 12GB / 16GB+）
- **流处理器/核心数**：并行计算单元数量
- **显存位宽**：数据通道宽度（128-bit / 192-bit / 256-bit）
- **功耗（TDP）**：显卡功耗，影响电源选择

## 使用场景

- **办公/影音**：集成显卡或入门独显
- **1080p 游戏**：RTX 3060 / RX 6600 级别
- **2K 游戏**：RTX 4070 / RX 7800 级别
- **4K 游戏/专业应用**：RTX 5090 / RX 7900 级别

## 选购要点

- 确认电源是否满足显卡供电需求
- 确认机箱是否有足够空间安装
- 确认显示器接口与显卡输出接口匹配
