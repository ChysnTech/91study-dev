# USB 接口

USB（Universal Serial Bus，通用串行总线）是目前最常用的外设连接接口。

## 主要版本

| 版本 | 速度 | 推出时间 |
|------|------|---------|
| USB 1.1 | 12 Mbps | 1998 |
| USB 2.0 | 480 Mbps | 2000 |
| USB 3.0 | 5 Gbps | 2008 |
| USB 3.1 | 10 Gbps | 2013 |
| USB 3.2 | 20 Gbps | 2017 |
| USB4 | 40 Gbps | 2019 |

## 接口类型

- **Type-A**：最常见的矩形接口
- **Type-B**：方形接口，用于打印机等设备
- **Type-C**：正反可插，支持高速传输和供电
- **Micro-USB**：早期手机常用
- **Mini-USB**：旧设备常用

## 充电标准

- **USB BC 1.2**：最大 1.5A / 5V
- **USB PD（Power Delivery）**：最高 240W
- **QC（Quick Charge）**：高通快充协议

## 应用场景

- 连接键盘、鼠标、U盘
- 手机充电和数据传输
- 外接显示器（Type-C / DisplayPort Alt Mode）
- 外置硬盘和扩展坞
