# 散热系统

散热系统负责将计算机组件产生的热量排出机箱，保证稳定运行。

## 风冷散热

- **原理**：金属散热片 + 风扇，通过空气带走热量
- **优点**：价格便宜，安装简单，可靠性高
- **缺点**：散热上限较低，噪音随转速增加
- **适用**：大多数 CPU（TDP ≤ 200W）

## 水冷散热

- **原理**：液体循环带走热量，通过冷排散热
- **优点**：散热效率高，外观美观
- **缺点**：价格较贵，存在漏液风险
- **适用**：高端 CPU、超频用户

### 水冷类型

- **一体式水冷（AIO）**：安装简单，主流选择（120 / 240 / 360mm）
- **分体式水冷**：可定制，维护复杂

## 风扇尺寸

- **120mm**：最常见，风量/噪音均衡
- **140mm**：风量大，噪音低
- **200mm**：超大静音风扇

## 选购要点

- 确认散热器与 CPU 插槽兼容
- 确认散热器高度与机箱宽度兼容
- 确认冷排安装位置与机箱兼容
